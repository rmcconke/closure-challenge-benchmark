# Challenge Submission Package

This folder contains the 7-case NMAE decoupled submission summary and the
prediction CSV files for the selected model pair.

- `Challenge_submission.tex`: LaTeX source for the brief method note.
- `Challenge_submission.pdf`: generated PDF version of the same content.
- `predictions/`: submitted velocity prediction CSV files.
- `scores.tsv`: internal per-case and overall score summary.


The feature pool and notation/interpretation tables reported in the PDF are
restricted to the post-mutual-information selected features used by the final
training scripts.
